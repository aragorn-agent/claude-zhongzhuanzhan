怎么选 Claude API 中转站（选型指南）

看数据，不要看广告。判断一家 Claude API 中转站是否靠谱，核心看四件事：

1. 在线率要看样本量

99% 在线率只有 5 个样本没有意义；本表只展示带真实样本数的站点，样本量越大越可信。低于 20 个样本的站点建议先小额试用。

2. 延迟要看 P50 而不是单次

Claude Code 场景对首字延迟敏感。平均延迟超过 8 秒的站点，长上下文请求会明显卡顿。

3. 价格对照官方价

表内 Opus 5.5 输入价已折算为每百万 token 人民币，可直接与官方牌价对比。低得离谱（低于官方 1 折）的站点要警惕降智与跑路风险。

4. 先小额后加量

任何中转站都建议先充最小额度跑 1~2 天真实业务，确认降智与否、稳定性如何，再决定是否加量。

常见问题

Claude API 中转站是什么？

提供与 Anthropic 官方相同格式的 API 接入服务，让 Claude Code、Cherry Studio 等工具通过一个 Base URL + API Key 接入 Claude / GPT / Gemini 等模型，通常按 token 计费，价格低于官方。

中转站会被封号吗？数据安全吗？

中转服务均非模型官方，存在上游配额变动与服务终止风险；敏感业务数据建议自行评估。建议避开需要上传完整代码库的站点。

榜单排名怎么来的？可以买排名吗？

排名由探测快照的在线率与样本量自动计算，无人为干预，不提供任何付费排名。数据缺失时显示 uncertain 或 —，不编造。

为什么不直接用官方 API？

官方 API 需要海外支付方式且按官方牌价计费；中转站支持支付宝/微信充值，价格更低。若预算充足且在官方服务区，官方 API 仍是首选。
